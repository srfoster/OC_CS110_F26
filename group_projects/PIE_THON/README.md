# Project Goal
Teach the user about how WMD's can discriminate against an arbitrary group of people even when they should be objectively favored.

## General Module Description
1. Randomly assigns the user two traits from a predetermined list of subjectively/objectively desirable/undesirable traits.
2. Surveys the user.
3. Produces an ethical/unethical decision based on the design of the model.

## Module 1
- Trait 1 = Subjectively undesirable by the model
- Trait 2 = Objectively desireable for the context
- Decision = Denied by the model

## Module 2
- Trait 1 = Subjectively desirable by the model
- Trait 2 = Objectively undesirable for the context
- Decision = Approved by the model

## Module 3
- Trait 1 = Subjectively undesirable by the model
- Trait 2 = Objectively desirable for the context
- Decision = Approved by the model

## Example Model
- Model goal = Approve/Deny loan applications based on credit score
- Trait 1 = From "X" zip code (proxied as undesirable by the model)
- Trait 2 = Credit score of 750 (generally good score, but weighed less by the model than zip code)
- Decision = Denied by the model
