# JUDGEMENT

- A text based game from the perspective of a prison warden that has the ability to either keep prisoners in prison or release them based on various scenarios.
- There are 3 difficulties: Easy, Medium, and Hard.
- Through these various modes you will find moral challenges put forward to a warden that doesn't have all the info in some cases.
- We hope you enjoy our game!
